# Запуск на Raspberry Pi через Media Station X

Текущий этап: Home server отдаёт существующую WEB-сборку и стартовый манифест MSX. WEB-клиент применяет подключения из админки — см. [клиентскую конфигурацию](client-config.md). CUB из него ещё не удалён. Установка и работа на физическом телевизоре ещё не проверены. Исходная форма манифеста: [`index/github/msx/start.json`](../index/github/msx/start.json). Локальный манифест заменяет placeholders адресом из проверенного Host. IPK для webOS остаётся отдельным будущим вариантом ([webOS](webos-packaging.md)).

На Pi с Docker Compose и 64-битной ОС в каталоге этого репозитория используйте существующий каталог `/root/.local/share/lampa-home/data` с `config.sqlite`. Не удаляйте его: там настройки и секреты. Сервис проверяет владельца процесса и права каталога 0700; для существующего root-каталога контейнер также работает от root. При другом расположении задайте `LAMPA_DATA_DIR` абсолютным путём к существующему приватному каталогу. Убедитесь, что путь и владелец соответствуют прежнему контейнеру.

Сначала обновите исходники и соберите новый образ, пока прежний сервис продолжает работать. Затем остановите прежний сервис тем же Compose-файлом, которым он запускался, и запустите новый без повторной сборки:

```sh
cd ~/apps/lampa-home
git pull
export LAMPA_BIND_IP=192.168.88.216
export LAMPA_DATA_DIR=/root/.local/share/lampa-home/data
docker compose -p lampa-home -f compose.pi.yml build
docker compose -p lampa-home -f compose.pi.local.yml stop lampa
docker compose -p lampa-home -f compose.pi.yml up -d --no-build
docker compose -p lampa-home -f compose.pi.yml ps
```

В примере путь к существующей базе задан явно. Без `LAMPA_DATA_DIR` используется `${HOME}/.local/share/lampa-home/data`, где HOME определяется окружением процесса Compose. При запуске под другим пользователем домашний каталог и владелец должны совпадать с существующей базой. Не используйте `down -v` или удаление каталога данных. При необходимости вернитесь к прежнему Compose-файлу после остановки нового сервиса. Если адрес Pi изменился, используйте фактический локальный IP в `LAMPA_BIND_IP` и MSX. Без переменной порт доступен только на loopback. Админка текущего прототипа не имеет авторизации: открывайте LAN-доступ только в доверенной сети.

В уже установленном Media Station X откройте **Settings → Start Parameter → Setup** и введите `192.168.88.216:8080`. Манифест находится по `/msx/start.json`, приложение — по `/app/`. Проверьте запуск и управление на самом TV; это ещё предстоит сделать. Для локальной диагностики откройте `http://192.168.88.216:8080/healthz` и `/msx/start.json`. Если манифест отвечает 503, WEB-сборка отсутствует; пересоберите образ. Изменения исходников требуют повторного `up -d --build`, а не установки npm-зависимостей при каждом запуске.
