ИИ-подборки

Промпты применяются только при новой генерации. Существующие карточки обновятся после явного обновления подборки. Модель выбирается из списка, как при сравнении; пункт «Другая…» принимает любой идентификатор OpenAI. Для главной в OpenAI передаются только явные лайки с названием и годом. Для похожих якорь — выбранное произведение с описанием, лайки только уточняют вкус. Модель использует web_search для поиска идей, а сервер находит предложенные названия в TMDB. История остаётся на сервере для исключения просмотренного.

Сброс снимает сегодняшние ручные обновления и платные попытки. Готовые подборки и журнал остаются. Уже выполненный автоматический запуск сегодня не повторяется.
